A Snapchain read node is already set up and synced at `https://167-233-111-186.sslip.io`. Run the app on your computer against it. No server or account is needed to read.

You need Node.js 22.12 or later (`node -v` to check; install from [nodejs.org](https://nodejs.org/en/download) or with `nvm install 22`).

```bash title="your computer"
git clone https://github.com/sudharshanx/runfarcaster
cd runfarcaster/client
npm ci --ignore-scripts
SNAPCHAIN_NODE_URL=https://167-233-111-186.sslip.io npm run dev
```

Open http://localhost:5317, type a username such as `dwr` and press **Show my feed**. To post, add an app key: see [Post with an app key](../first-cast/#2-add-an-app-key). Only paste a seed phrase into software from developers you trust, and prefer a delegated signer where you can.

:::note
This node runs until Oct 24, 2026. To vouch, do the [Full run](../quickstart/): your own server, node and app. A coding assistant can run it with you: [Set up with AI](../ai-assistant/).
:::
