title: Instant run has ended
description: The shared node behind Instant run is gone. Run RunFarcaster on a node of your own instead.
---

Instant run let you try the app against a node we had already synced, with no server of your own. We shut that node down on 20 October 2026. If you came here from a post on Discord or Farcaster, thank you for trying it, and sorry the link no longer leads to something live.

If you already ran the Instant run command, the app now can't connect to a node. Nothing on your computer is broken; the server it was reading from is gone.

To carry on, run your own node. It's the same app, reading from a server that you rent and run:

- [Set up with AI](../ai-assistant/): a coding assistant runs the three commands with you.
- [Full run](../quickstart/): run the three commands yourself.

Our own run synced in 14 h 06 m on a Hetzner cax31 and cost $2.31 up to that point. The server keeps billing until you delete it with `teardown.sh`: $102.29 a month for that setup. [Proof](../proof/) has every number.
