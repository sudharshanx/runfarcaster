## The three commands

```bash title="your machine"
# 1. Rent the compute: VM + data volume + firewall on Hetzner. Prints the IP.
IP=$(SSH_KEY=my-key SERVER_TYPE=cax31 VOLUME_GB=1000 \
     MAX_USD=5 EXPECTED_HOURS=16 ./provision.sh)

# 2. Turn it into a Snapchain read node and wait for sync (hours).
ssh root@$IP "SNAPCHAIN_AGREE_NO_REWARDS=yes MIN_FREE_GB=900 \
  bash -s" < node.sh

# 3. Serve the web client from the node over HTTPS.
./deploy-client.sh "$IP"
```

Stop the bill: `CONFIRM=snapchain-read-node ./teardown.sh`.
These are the settings we ran (cx43 was sold out; new accounts have a 1024 GB volume quota). On a 1 TB volume, also install the two disk helpers shown in the [Quickstart](quickstart/).
