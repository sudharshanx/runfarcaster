Paste one prompt into Claude Code, Codex, Cursor or another coding assistant that runs shell commands. It walks you through the 3 steps one at a time, and shows you each command and what it costs before it runs anything.

:::danger[Keep two things out of the chat]
Your recovery phrase and any private key: the assistant never needs them. Your Hetzner token: keep it in `HCLOUD_TOKEN` in your own shell.
:::

## Run all 3 steps

Set your Hetzner token in a terminal, then start the assistant from that terminal. The commands it runs read the token from there, so it never enters the chat:

```bash title="your computer"
read -rsp 'Hetzner token: ' HCLOUD_TOKEN && export HCLOUD_TOKEN && echo
```

### Renting and deleting are your call

Two steps change your Hetzner bill: renting the server and deleting it. For each one, the assistant shows you the command and the price, then you choose. It can run the command once you say yes, or you can paste it into your own terminal and share the output. Either works, and some assistants suggest the second on their own. Everything in between (starting the node, putting the app on the server, checking the sync) the assistant runs for you, asking before each step.

If you run them yourself, in the `runfarcaster` folder, these are the two commands. Put your SSH key's name in place of `my-key`, and use the same `NAME` as the assistant:

```bash title="your computer"
MY_IP=$(curl -4 -s https://ifconfig.me)
echo "$MY_IP"
export NAME=snapchain-read-node
IP=$(SSH_KEY=my-key SERVER_TYPE="" VOLUME_GB=1000 WATCHDOG=0 \
  SSH_SOURCE_CIDRS="$MY_IP/32" ./provision.sh)
```

```bash title="your computer"
CONFIRM="$NAME" ./teardown.sh
```

The assistant then finds the server itself with `IP=$(hcloud server ip "$NAME")`. Until you delete it, Hetzner keeps billing: on cax31 with IPv4 and the 1000 GB volume, $0.164 an hour and at most $102.29 a month.

## The skill

The longer prompt runs this command. To install the skill yourself, run it in your project folder:

```bash
npx skills add sudharshanx/runfarcaster --skill runfarcaster
```

Add `-g` to install it for every project, or `-y` to skip the questions about which agents get it. It uses the open [Agent Skills](https://agentskills.io/) format, which Claude Code, Cursor, Codex and other agents load. A skill runs with your agent's permissions; the files are in <RepoLink path="skills/runfarcaster/" />.
