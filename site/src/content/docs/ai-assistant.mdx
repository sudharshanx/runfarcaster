## Install the skill

The RunFarcaster skill gives a coding agent the 3 steps, the fixes and the safety rules. It uses the open [Agent Skills](https://agentskills.io/) format, so Claude Code, Cursor, Codex and other agents can load it. Run this in your project folder:

```bash
npx skills add sudharshanx/runfarcaster --skill runfarcaster
```

Add `-g` to install it for every project. Or ask your coding agent:

```text
Install the RunFarcaster skill from github.com/sudharshanx/runfarcaster
```

The files are in <RepoLink path="skills/runfarcaster/" />. Read them before you install: a skill runs with your agent's permissions.

The whole site as plain text, for assistants: [`llms.txt`](../llms.txt) (summary) and [`llms-full.txt`](../llms-full.txt) (every page in Markdown).
