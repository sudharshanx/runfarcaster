Paste one prompt into Claude Code, Codex, Cursor or another coding assistant that runs shell commands. It installs the RunFarcaster skill, follows it through the 3 steps, and asks before each one.

:::danger[Keep two things out of the chat]
Your recovery phrase and any private key: the assistant never needs them. Your Hetzner token: keep it in `HCLOUD_TOKEN` in your own shell.
:::

## The skill

The prompt runs this command. To install the skill yourself, run it in your project folder:

```bash
npx skills add sudharshanx/runfarcaster --skill runfarcaster
```

Add `-g` to install it for every project, or `-y` to skip the questions about which agents get it. It uses the open [Agent Skills](https://agentskills.io/) format, which Claude Code, Cursor, Codex and other agents load. A skill runs with your agent's permissions; the files are in <RepoLink path="skills/runfarcaster/" />.
